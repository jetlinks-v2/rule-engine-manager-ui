# 指标管理

对象类型入口以紧凑的图标、当前名称与下拉箭头组成，箭头紧邻名称；悬停和键盘焦点提供背景反馈，收起按钮独立靠右。类型名称按可用宽度省略，选择与键盘操作沿用原 Select。

指标工作区复用 core 的 `ResponsiveSplitter` 与 `PanelCollapseButton`，使用 `gutter=0` 让结构线连续相接，展开、折叠和窄容器保持恢复操作。`FullPage` 提供可用高度，路由通过 `getContentPanelOverrides()` 设置面板 `padding: 0`；对象标题、视图和查询工具固定，仅下方指标/统计数据区域滚动。左侧维度行提供收起入口，搜索和对象列表位于其下；宽窄切换保留同一个导航实例及其选择、搜索和滚动位置。指标/汇总统计切换位于对象标题旁的轻量下拉中。汇总工具栏省略重复前缀，将范围、指标、时间和刷新紧凑放在同一行，空间不足时换行；候选说明不进入选中值。附加输出列以 120px 的内容预算适配紧凑卡片，空间不足时自然换行；状态值与说明图标并排，不强制说明另占一行。

卡片按主读数、必要说明、趋势/状态记录和更新时间组织，数值、布尔与状态时长沿原语义展示；紧凑质量提示使用图标与完整说明，错误原因及时间下界不省略。状态时长区分本次状态与“上次{状态}”，不把上一次的状态混入当前读数，也不推算未知区间。

星标设置当前配置的共享重点，所有有权查看的用户消费同一状态，默认在同一来源列表内优先展示；来源选择器沿用相同次序。顶部居中的把手支持同归属、同重点组内拖拽和方向键移动，更多菜单仅保留编辑、启停、删除及来源操作；删除项单独分隔，图标使用统一插槽对齐。标题栏图标按钮统一 28×28 点击区域、悬停和焦点样式。继承与只读指标保留来源入口；重复的显式关联从原卡片“关联来源”菜单解除，不删除源配置。失败保留原共享状态和次序，展示变更不改变计算版本。接口和跨来源目录分页见[共享重点契约](../../../../../modules/jetlinks-components/things-component/docs/通用指标平台接口骨架草案.md#共享重点指标与默认顺序)。

星标和排序保存仅在当前星标或拖拽把手的固定位置显示进度，其他卡片不显示保存动画。服务端确认后直接应用返回的展示声明与修订，保留读数、趋势和模板；已有后台读取不能覆盖新确认的状态，也不延长保存中的反馈。点击星标后保持当前页的卡片位置，后台更新也不立即重排；手动刷新、切换对象或重新进入页面时再应用共享重点优先。拖拽属于显式排序，仍按操作结果调整同组卡片位置。

本目录统一拥有指标业务：模板设计、发布、试算、配置编辑、关联管理、结果渲染、只读计算图、历史、汇总、成员分页与工作区。指标专属 API、状态、类型、国际化和测试随实现保留在规则模块。

指标界面完整提供中文、英文和日语，包含来源选择、模板设计、算法说明、试算、历史与汇总。公共文案由本目录字典管理，主日语字典位于 `ja.ts`；聚合名称、算法描述与校验提示使用后端对应语言资源。模板和用户自定义名称按自身展示声明保留，不根据算法编码猜测翻译。新增文案需同步三种语言并保持插值参数一致，避免局部字典合并时遗漏日语。

模板计算方式切换在清除原方式配置前确认，取消保留草稿；无效节点提供可见撤回入口，提交仍受校验保护。持续条件默认展示成立与恢复条件摘要，按需展开单项公式编辑；无数据中断时长沿后端正时长要求明确提示。参数显示是否已被计算引用，数值格式设置依输出语义显露；模板可选性动作明确仅影响新配置。指标应用的来源错误随当前绑定与解析状态恢复，属性面板的展开动作在桌面和窄屏均显示配置内容。

结果列表会省略输入绑定及参数等管理信息。编辑已有配置时先通过管理入口重新授权并读取完整配置，再装配来源和草稿；启停及重命名同样在完整配置上修改，防止写回精简结果而丢失绑定、参数和修订号。管理读取失败或切换对象后，旧响应不能更新当前草稿。

来源选择与后端保存仅按声明的数据类型和结构兼容性匹配，数值类型通用，对象、数组和枚举保留原类型约束。单位和语义保留为元数据，不用于过滤来源，也不隐式换算数值；来源权限、引用有效性及读取能力校验保持独立。

来源目录为空时显示实际查询空态；未声明类型或语义不会产生额外的选择门槛。公开辅助函数与测试仅维护实际生效的类型／结构筛选，语义元数据提取仍用于声明导入。

来源选择内嵌在属性面板时，标题、来源对象与搜索固定，候选列表占满剩余高度并独立滚动；不沿用独立弹窗的列表高度上限，也不滚动整个编辑区。对象候选和成员统计的长内容同样在来源区域内滚动。

`views/Metric` 和 `views/MetricTemplate` 承接管理菜单；`register.ts` 通过现有 `components` 资源公开 `MetricScopePanel`，设备等模块通过 `RemoteComponent` 使用，避免导入业务模块的私有文件。管理请求保留运行时请求上下文、精确数值解析及原有权限、修订冲突和未保存草稿保护。

`@rule-engine-manager-ui/metric` 是跨模块使用指标类型、查询、纯辅助函数与来源适配的公开入口。来源选择器随指标管理归本模块，只请求 `/metric/configs/sources/**`；管理服务内部桥接 relation 和已安装的可选来源，前端不依赖本体接口。设备与空间提供对象上下文、领域模板和导航，通过资源扩展点嵌入指标面板。

分布趋势图使用挂载到页面 body 的 ECharts HTML 提示浮层，按可用空间定位，使紧凑图表中的完整状态列表不受画布高度或卡片裁切限制。

未声明输出类型的普通公式也可按需读取服务端历史聚合能力，选择平均值、最小值、最大值或末值；实际操作及禁用限制由服务端决定。数值聚合桶按数值绘制，不补写模板类型；没有有效数值的时段保留空白。

历史详情首次读取时保留图表高度并展示骨架；刷新与切换时段保留已有曲线，等待超过短延迟后显示加载遮罩。数值曲线关闭入场动画，数据就绪后直接呈现，不改变查询口径或刷新频率。

数值趋势统一接受精确 JSON 解析保留的高精度数值字符串，仅在生成绘图坐标时转为有限 number，原始读数不变。空值、空白、非数值、无穷大及无效质量仍作为断点；均值等聚合与原始数值历史共用该规则。

历史图表容器统一承载时间范围、刷新、聚合选择与当前图表工具，宽屏共用一行、窄屏自然换行。选择器收起时只显示名称，候选说明留在展开列表；图表操作按完整按钮组换行，不把限制提示单独挤到下一行。数值趋势和状态时间轴共用此布局，独立使用图表时仍保留自身工具栏。

详情的统计口径与单位统一放在图表顶部说明。统计窗口、变化率时间单位和执行频率分别沿后端 resultSemantics 展示；一分钟窗口的斜率仍可按每秒变化率表达，均值使用原量纲，不根据配置名称推断算法或转换结果数值。

core 承载通用公式、画布、图表、对象关系与本体契约及通用选择组件；公式的变量和函数由调用方提供，不请求指标 API。本体业务页面留在本体模块，运行监控、报表等其他 Metric 能力按其业务语义归属。
